# Testimonial Card

A responsive testimonial card component built with vanilla HTML and CSS.

## Overview

This project implements a single testimonial card featuring an author's
profile photo, name, handle, and quote, styled with a soft drop shadow,
rounded avatar, and a subtle gradient page background.

## Features

- Semantic HTML using `<figure>` / `<figcaption>` / `<blockquote>`
- Flexbox-based layout for the card and author row
- Custom typography via the Noto Sans Google Font
- Card styled with rounded corners and layered box-shadow
- Centered, responsive layout that adapts to small viewports

## Tech stack

- HTML5
- CSS3 (Flexbox)

## Running locally

Open `index.html` directly in a browser, or serve the folder with any
static file server, e.g.:

```bash
npx serve .
```
